1. Benchmark C++ Puro (llama-bench)

Sin Overhead HTTP

Mide la velocidad exacta del motor C++ probando distintos números de hilos (-t) para encontrar el punto óptimo real de tu CPU (evitando cuellos de botella por HyperThreading).

Haz clic en "Medir C++" para comparar la velocidad de generación (t/s) según el número de hilos.

Diagnóstico

4. Cuantizador GGUF (llama-quantize)

Compresión

Comprime o recuantiza un modelo GGUF local para que ocupe menos RAM y genere tokens más rápido en CPU o Android Termux.

El modelo cuantizado se guardará automáticamente en la carpeta models/.
